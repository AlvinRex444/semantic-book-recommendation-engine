# semantic-book-recommendation-engine
Working: User Query → Sentence-BERT Embedding → FAISS Index Search → Top-K Similar Books

## Why Semantic Search?
Unlike keyword-based systems, this model understands context and meaning using embeddings, enabling more accurate recommendations.

Book recomendation-engine for rating of books for content based searches with vector searches through FAISS

Designed and developed a high-performance semantic recommendation system that retrieves contextually similar books using transformer-generated embeddings and Approximate Nearest Neighbor (ANN) search, it also auto corrects user query by using library rapidfuzz.
